把口播视频或文案转成带对象标注的讲解动画，支持真人画中画和多种画幅。它最硬的一条流程是文案前置校对：有源口播就核听转写成完整校对稿，没有音频则按主题和时长起草，稿件必须先给你确认，才允许进入依赖文案的配音、付费图像和动画生成。之后按脚本、共享与变体素材、镜头、声音、合成逐步推进，多镜共享人物或产品时先建立并审核共用视觉锚点，再生成依赖镜头。成片后它还会主动推荐三个可选完善层：字幕、右下角真人圆形画中画和器乐 BGM，你选哪个才做哪个，不选就交付纯动画主版本。全程版本、路径和审核结果都有记录，可中断恢复。

### ✨ 能做什么

- 口播视频或文案 → 带对象标注的讲解动画，支持真人画中画与灵活画幅
- 文案前置校对：先出校对稿等你确认，之后才做配音与付费生成

## 🇬🇧 English

Turns a talking-head video or script into an explainer animation with object callouts, supporting real-person picture-in-picture and flexible aspect ratios. Its hardest rule is script pre-review: if there is source audio it transcribes and proofreads a full script, otherwise it drafts one from topic and runtime, and the script must be confirmed by you before any script-dependent voice-over, paid image generation or animation runs. Work then proceeds through script, shared and variant assets, shots, sound and composition, and any character or product reused across shots gets a shared visual anchor built and reviewed before dependent shots are generated. After the main cut it proposes three optional finishing layers — subtitles, a bottom-right circular picture-in-picture and instrumental BGM — and only runs the ones you pick, otherwise delivering the pure-animation version. Versions, paths and review results are logged throughout so work can resume.

### ✨ What it does

- Turns a talking-head video or script into a callout explainer animation with picture-in-picture and flexible aspect ratios
- Runs script pre-review: a proofread script is confirmed first, only then voice-over and paid generation
- Builds and reviews a shared visual anchor before generating shots that reuse a character or product
- Shot table records narrative role, paragraph event anchor, planned duration, framing and lip-sync handoff
- Offers three optional finishing layers after the main cut: subtitles, circular picture-in-picture and instrumental BGM
- Re-lays out subject, graphics and captions when aspect ratio changes instead of blind center-cropping; versions and paths are logged
